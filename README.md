## 功能

- **我的城市**（首页，`#city`）
  - 选择城市（按一线 / 二线 / 三线分组，记在本机），默认杭州
  - 一句话结论，例如「二手房价已连续 4 个月下跌，比 2021 年底累计跌 13.2%」
  - 新建、二手各四个数：环比、同比、比 2021/12 累计、距高点（含高点月份）
  - 累计走势：新建 vs 二手两条线，2021 年 12 月 = 100，悬停看每月指数和环比
  - 按面积分段（90㎡ 以下 / 90–144㎡ / 144㎡ 以上）的最新环比、同比
- **全国**（`#nation`）：本月几城涨 / 平 / 跌；每月涨跌城市数堆叠柱（看「止跌」信号）；一线 / 二线 / 三线同比走势；北上广深卡片
- **排行**（`#rank`）：70 城按环比、同比、累计、距高点、连续涨跌月数排序，可切新建 / 二手、按城市等级筛选，涨跌用色块深浅表示
- **对比**（`#compare`）：最多 4 个城市的累计走势叠在一起
- **杭州小区**（`#map`）：高德底图上的杭州成交活跃小区（每月约 500 个）
  - 圆点按成交均价或环比着色，悬停看均价和环比，点开看历月均价走势、同比、同区县均价相近的小区
  - 筛选月份、区县，搜小区名；各区县的小区数、均价中位数、上涨 / 下跌占比；小区列表可按均价、上月、环比排序
  - 详情地址可分享：`#/item/xq/<区县>|<小区>`
- 右侧挂件：本月涨跌城市数、下次发布倒计时（统计局通常次月 15–20 日发布）、指标说明、来源状态
- 右上角：↻ 重新读取数据，⚡ 跳转 GitHub Actions 手动触发抓取，☾ 深浅色；手机适配，图表按屏幕宽度重画
- 颜色：红涨绿跌

## 技术架构

70 城房价指数（GitHub Actions 自动）：

```
GitHub Actions（触发：每天 10:17 北京时间 / 手动 dispatch / push 修改 scraper.py 或 workflow）
  ↓ python scraper.py（Python 3.12，只用标准库）
  ↓ 翻统计局「最新发布」列表 → 找到每期「X 月份 70 个大中城市商品住宅销售价格变动情况」
  ↓ 缺的月份逐个抓发布稿、解析表 1～6（最新一期总是重抓，防止更正）
  ↓ 计算摘要：本月涨跌城市数、一二三线均值、北上广深
  ↓ 写入 data.json（updated 每次都变 = 心跳）→ git commit → push
       ↓
GitHub Pages（index.html 读取 data.json；累计、高点、排行、图表都在前端计算）
  ↓ 五个视图：我的城市 / 全国 / 排行 / 对比 / 杭州小区
  ↓ kit 详情抽屉（#/item/<类型>/<id>）
```

杭州小区（只能在 macOS 本机手动跑，每月新榜单出来后一次，不在 Actions 里）：

```
python3 xiaoqu.py <杭州网涨跌榜文章网址>     # 登记新的一期；不带参数 = 重新处理已登记的各期
  ↓ 文章所有分页的配图 → .cache/xiaoqu/<文章编号>/（不提交）
  ↓ ocr.swift（macOS Vision，长图切段识别）→ 以「均价」数字为锚点分行，左侧是小区名，标题里取月份和区县
  ↓ 疑似识别错的格子裁出来放大、去浅色水印后重新识别；仍对不上的写进 .cache/xiaoqu/review.txt，人工修正写进 xiaoqu_fix.json
  ↓ 新小区查高德坐标（缓存 xiaoqu_geo.json）→ 合并别名
  ↓ 写入 xiaoqu.json → 手动 git push
       ↓
GitHub Pages（切到「杭州小区」时才加载 Leaflet 和 xiaoqu.json，高德瓦片底图）
```

| 来源 | 方式 | 每次条数 / 范围 | 备注 |
|---|---|---|---|
| [国家统计局 · 最新发布](https://www.stats.gov.cn/sj/zxfb/) 列表 | 网页解析（列表页正则） | 已有完整数据时只看前 3 页；没数据或中间缺月时一直翻到 2022 年 1 月之前 | 取每期发布稿的地址和发布日期 |
| 统计局发布稿表 1 / 表 2 | 网页解析（HTML 表格） | 每期 70 城 × 新建、二手；当前 57 期（2022-01～2026-09） | 环比、同比、年内平均；1 月份没有「年内平均」列，用同比代替（两者相等） |
| 统计局发布稿表 3～6 | 网页解析（HTML 表格） | 70 城 × 3 个面积段；只保留最近 13 个月 | 90㎡ 以下 / 90–144㎡ / 144㎡ 以上 |
| [杭州网](https://hznews.hangzhou.com.cn/jingji/)「杭州二手房价涨跌榜」 | 网页解析 + 图片 OCR（macOS Vision） | 每月一期，每期约 300～600 个小区；目前 8 期（2025-09、2025-12、2026-02、04、05、06、07、09），共 1278 个小区 | 潮新闻美好生活研究院发布，表格注明数据来源中指研究院；只在本机运行 |
| [高德开放平台](https://lbs.amap.com/api/webservice/guide/api/georegeo) | 接口（地理编码 v3/geocode/geo，查不准时用 POI 搜索 v5/place/text） | 只查新小区；POI 搜索每次运行最多 80 次（`SEARCH_BUDGET`） | 高德坐标系，和底图一致；结果缓存在 `xiaoqu_geo.json` |

**配置位置**
- `scraper.py` 顶部：`BASE`（列表地址）、`START = "2022-01"`（回填起点）、`SIZE_MONTHS = 13`（面积分段保留月数）、`TIER1` / `TIER2`（一线 / 二线城市名单，其余为三线）；列表页匹配标题的正则在 `list_page()`
- `xiaoqu.py` 顶部：`ADCODE`（杭州 13 个区县 → 行政区划代码）、`GEO_LEVELS`（地理编码可接受的返回级别）、`SEARCH_BUDGET`；登记的文章存在 `xiaoqu.json` 的 `articles` 里

**增删来源**
- 70 城：统计局只有这一个来源；要改回填起点改 `START`，要调整城市分级改 `TIER1` / `TIER2`
- 杭州小区：新的一期 = `python3 xiaoqu.py <文章网址>`；删除某期 = 从 `xiaoqu.json` 的 `articles` 里删掉对应条目后不带参数重跑
- 要加别的城市的小区数据，需要新写解析脚本并输出同结构的 json，前端地图目前写死杭州（中心点 `[30.27, 120.17]`）

**限制**
- 统计局只发布**指数**（上月 / 上年同月 = 100），不发布每平米价格；小区均价目前只有杭州
- 统计局网站可能拦截海外服务器；如 Actions 抓取失败，可在本机运行 `python3 scraper.py` 后推送（每月一次即可）
- 杭州小区只含当月「成交活跃」上榜的小区；单个小区均价受当月成交房源结构影响，环比波动较大；表格由图片识别，个别数字可能有误
- 链家 / 贝壳 / 我爱我家的成交价只在 App 里显示，网页翻页每页都要人机验证，所以不用它们的数据

## 数据处理规则

**70 城（scraper.py）**
- `fetch()`：带桌面 Chrome UA 和 `Accept-Encoding: gzip`，超时 40 秒，自动解压
- `list_page(n)`：第 0 页 `index.html`，之后 `index_<n>.html`；按标题正则「YYYY年M月份70个大中城市商品住宅销售价格变动情况」取地址，在链接后 800 字内找发布日期
- 翻页规则（`main()`）：数据为空、或从 `START` 到已有最新月份之间有缺月时 `need_backfill`，一直翻到列表里最早月份早于 `START`；否则只翻 0～2 共 3 页；每页间隔 1 秒，翻到 404 就用已找到的
- 待抓月份：列表里有、但 data.json 没有的月份，加上列表里的最新一期（总是重抓）；每期间隔 1.5 秒
- `parse_release(url, tries=3)`：页面里 `<table>` 少于 6 个或「北京」出现不到 2 次视为不完整（疑似限流），重试并依次等 5 / 10 / 15 秒
- 表 1 / 表 2 `main_table()`：每行并排两个城市，每城 4 格（城市、环比、同比、年内平均）；1 月份每城只有 3 格，年内平均用同比补；城市名需是 2～5 个汉字、三个数都能解析；新建或二手少于 60 城则判定失败
- 表 3～6 `size_tables()`：每行 7 或 10 格（1 月份 7 格，每段只有环比、同比，年内平均用同比补），切成 3 个面积段 × [环比, 同比, 年内平均]
- 面积分段只保留最近 13 个月，更早月份删除 `new_size` / `used_size`
- 摘要：`counts` 按环比指数 > 100 / = 100 / < 100 统计涨 / 平 / 跌城市数；`tiers` 为各等级城市 [环比, 同比] 的简单平均（保留 2 位）；`tier1` 为北上广深原始三元组

**前端指标（index.html）**
- 指数转涨跌幅：`idx2pct(v) = v − 100`
- 累计 `chain()`：从 2022-01 起每月环比连乘，2021 年 12 月 = 100；属推算值，用「最近 12 个月环比连乘 vs 同比」交叉验证，70 城平均误差约 0.1 个点、最大 0.4
- 距高点 `cityStats()`：当前累计指数 / 期间最高点（含基期 2021-12 = 100）− 1，并记录高点月份
- 连续涨跌月数：从最新月往前数，环比方向（> 100 或 < 100）相同的连续月数，持平即中断
- 全国视图：每月涨 / 平 / 跌城市数堆叠柱；城市详情里「二手同比 70 城第 N」按二手同比从高到低排名；「走势相近」取同等级城市中二手累计最接近的 6 个
- 下次发布倒计时：按上一期发布日推算次月 15 日起，提示「预计 X 月 15–20 日」

**杭州小区（xiaoqu.py）**
- `article_images()`：从文章地址解析编号和发布日期，读取全部分页（`content_<id>_<n>.htm`），收集正文配图
- `ocr()`：调用 `ocr.swift` 编译出的 `.ocr_bin`（源码比二进制新时自动 `swiftc -O` 重编），结果按图片缓存成 `.tsv`
- `parse_image()`：标题正则取月份和区县（区县必须在 `ADCODE` 里，表格跨图片时沿用上一张的区县）；价格数字（4～6 位、可带千分位）按横坐标最大间隔（> 图宽 8%）分成「本月 / 上月」两列；以价格为锚点按行高中位数 × 0.45 的容差分行，左侧文字拼成小区名（去掉表头词和「潮新闻 NEWS」水印残留）
- 环比一律用两个均价重算：`round((本月 / 上月 − 1) × 100, 1)`；与识别出的 % 相差 > 0.15 时打标记
- `refine_prices()`：缺本月均价、重算环比绝对值 > 25%、或与识别值对不上时，裁出均价格放大（倍数 ≥ 3）并去浅色后重新识别，缓存 `.prices.json`
- `refine_names()`：名字为空或含非中文字符时裁出名字格重新识别，缓存 `.names.json`
- `month_of()`：标题月份大于发布月份时算作上一年
- 过滤：`xiaoqu_fix.json` 的 `drop` 行丢弃，`rename` 改名（可限定某一期）；有标记且不在 `ok` 名单里的行写进 `review.txt`，其中「名称」「缺本月」两类不入库
- `geocode()`：先用「杭州市+区县+小区名」地理编码，返回级别在 `GEO_LEVELS` 且区县一致才采用；否则用 POI 搜索（限定区县、类型 120300 / 120000，每次运行最多 80 次）；额度 / key 错误时停止，下次接着查；`xiaoqu_fix.json` 的 `geo` 手动坐标优先
- `merge_aliases()`：坐标完全相同、一个名字包含另一个、从没在同一期同时出现、名字不含「别墅 / 排屋 / 叠墅 / 洋房 / 公寓 / 括号」、且每期均价与主名字最近一期相差 < 15% → 合并到出现期数最多的名字
- 前端补点 `xqSeries()`：某月没上榜但下个月表里有「上月均价」时用它补；小区同比 = 最近一期均价 / 去年同月均价 − 1

## 前端

单页 `index.html`，原生 JS，无构建；`fetch('data.json?t=<时间戳>', { cache: 'no-store' })` 读取数据，切到「杭州小区」时再从 cdnjs 加载 Leaflet 1.9.4 和 `xiaoqu.json`。

**kit 详情抽屉**（内联在页面里的通用组件 `KIT`）
- 点击城市、月份柱、小区打开详情抽屉：电脑端从右侧滑出，手机端（≤ 760px）从底部升起；`Esc`、点遮罩或浏览器返回关闭
- 详情地址 `#/item/<类型>/<id>`，写进地址栏，分享链接可直接打开（data.json 读完后 `KIT.boot()`；小区链接会先显示「正在读取小区数据…」，xiaoqu.json 读完后再弹出）
- 链接里的条目在当前数据中找不到（已下榜 / 过期 / 旧链接）时，弹出「这条内容已不在当前数据里」提示，并给「回到首页」按钮

本项目的条目类型：

| 类型 | id | 内容 |
|---|---|---|
| `city` | 城市名，如 `北京` | 新建 / 二手各项指标（环比、同比、累计、距高点、高点月份、连续涨跌）、累计走势图、面积分段、同等级走势相近的 6 城；按钮：设为我的城市、统计局原文 |
| `month` | 月份，如 `2026-09` | 该月新建 / 二手上涨、持平、下跌城市名单，前后月份 |
| `xq` | `<区县>\|<小区名>`（URL 编码） | 小区最近一期均价、环比、同比、历月均价走势、各期表格、同区县均价相近的 6 个；按钮：在地图上看、高德地图、原文 |

本项目没有注册 `#/list/<key>` 列表页；五个视图用单段 hash 切换：`#city`、`#nation`、`#rank`、`#compare`、`#map`。

**项目特有功能**
- 我的城市（默认杭州）、排行的类型 / 排序 / 等级筛选、对比城市（默认北京、上海、杭州、深圳，最多 4 个）、全国视图类型等都记在 `localStorage`，键前缀 `hp70.`
- SVG 折线图按容器宽度重画，鼠标悬停 / 手指按住看每月数值
- 杭州小区地图：高德瓦片底图 + Leaflet 圆点；按成交均价（6 档：1.5 万以下 … 7 万以上）或环比（6 档：跌 5% 以上 … 涨 5% 以上）着色；月份、区县筛选、搜小区名；区县统计表（小区数、均价中位数、上涨 / 下跌占比、最高）；小区列表按均价 / 上月 / 环比 / 名称排序，每次显示 60 个

## 本地运行

python3 scraper.py        # 首次回填约 5 分钟（57 期，每期约 1.5MB，限速下载）

## 自动更新机制

| 触发方式 | 时机 |
|---|---|
| GitHub Actions 定时任务（cron `17 2 * * *`） | 每天 10:17 北京时间（统计局一般 9:30 发布） |
| push 到 main 分支 | 仅当改动了 `scraper.py` 或 `.github/workflows/scrape.yml` |
| GitHub Actions 手动 dispatch | 按需触发（页面右上角 ⚡ 直达） |
| 本机手动运行 `xiaoqu.py` 并 push | 每月杭州网新榜单发布后一次（不在 Actions 里） |

- workflow：`.github/workflows/scrape.yml`，只更新 `data.json`；`concurrency: scrape`（不取消进行中的任务），权限 `contents: write`
- 运行完执行 `git add data.json`，有变化才提交（提交信息 `data: update <北京时间>`），然后 `git pull --rebase` 再 push
- **心跳**：data.json 里的 `updated` 每次运行都会变，所以每次运行都有提交，仓库保持活跃
- GitHub 规定：仓库 60 天没有提交会自动停用定时任务；有了上面的心跳一般不会触发，若被停用需到 Actions 页面手动重新启用
